# 专注力游戏配乐

30 首无歌词原创程序作曲，6 个主题 × 5 个变奏，各有 15 首轻松与轻悬念配乐。
素材由仓库根目录 `generate_focus_music.py` 用正弦波、谐波及轻打击声合成，非真人乐器录音，也不是 AuK 生成的音乐。

| 主题 | 风格 | 情绪 |
| --- | --- | --- |
| sunny-steps 晴天脚步 | 轻快拨弦 | 轻松 |
| garden-bells 花园风铃 | 柔和风铃 | 轻松 |
| cloud-picnic 云上野餐 | 柔和电钢琴 | 轻松 |
| curious-path 好奇小径 | 木琴探索 | 轻悬念 |
| quiet-mission 安静任务 | 轻电子脉冲 | 轻悬念 |
| puzzle-spark 谜题火花 | 柔和街机合成器 | 轻悬念 |

每首为 16 小节约 32～45 秒的立体声循环，MP3 96 kbps，全部约 14 MB。
变奏改变旋律顺序、调性与速度；同主题共享音色。曲目元数据见 `catalog.json`。
重新生成：`python generate_focus_music.py`（需要 numpy 与 ffmpeg）。

本地试听：`http://127.0.0.1:8080/music-library.html`。
`focus-music.js` 为 20 款游戏分配各不相同的默认曲目，其余曲目作备选。
游戏音量为 16%；可切换轻松/轻悬念风格及关闭配乐，关闭偏好保存在浏览器。
游戏五词语播放、游戏十倒计时和视听播放期间暂停配乐，声音试听时也暂停；作答时恢复。
返回首页、训练结束、离开 Focus 标签页或页面隐藏时停止/暂停配乐。
