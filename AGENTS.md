# Project Guidelines & Agent Instructions

This project adheres strictly to **Andrej Karpathy's Behavioral Guidelines** to eliminate common AI coding pitfalls:

## 1. Think Before Coding (先问后做，禁止擅自脑补)
- **Do not assume**. If a prompt or requirement is underspecified, ambiguous, or has multiple interpretations, **STOP AND ASK FIRST**. Never pick silently and implement.
- Surface trade-offs, state assumptions clearly, and get confirmation before writing code or generating assets.

## 2. Simplicity First (极简至上)
- Minimal code that solves the problem. No speculative features, no premature abstractions.
- Keep implementations compact and straightforward.

## 3. Surgical Changes (外科手术式修改)
- Touch only what was requested.
- Do not reformat, refactor, or "improve" unrelated code or files.
- Match existing style and conventions.

## 4. Goal-Driven Execution (目标驱动与闭环验证)
- Establish verifiable checks before marking any task as done.
- Ensure all automated tests pass before concluding.
